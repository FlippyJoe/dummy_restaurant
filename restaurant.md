# Dynamic Restaurant Menu – Fetch API Update 🍽️

This project is part of my front-end web development learning journey. It's an updated version of a dummy restaurant website I built previously. Originally, the menu data was hardcoded directly in JavaScript as an object. In this improved version, the menu is now dynamically loaded from an external JSON file using the Fetch API. 📦

## 🔗 Live Demo

[Check out the live menu here](https://flippyjoe.github.io/dummy_restaurant/menu.html)

## 🚀 Key Features

- 📥 **Fetch API Integration**: Menu data is loaded dynamically from a JSON file.
- 🧾 **Category Grouping**: Menu items are automatically grouped into categories like Starter, Main, Dessert, etc.
- 🔠 **Sorted Items**: Items are sorted alphabetically within each category.
- 🎯 **Custom Order**: Categories are displayed in a custom logical order.
- 👁️ **Intersection Observer**: Smooth visual effects when elements scroll into view.
- 💡 **Graceful Error Handling**: Displays a user-friendly message if something goes wrong.

## 💻 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- JSON

## 🧠 What I Learned

- Using the `fetch()` API to handle asynchronous data loading.
- How to structure and parse external JSON data for use in the DOM.
- Applying `IntersectionObserver` to enhance UX with animation effects.
- Organizing JavaScript logic in a readable, maintainable way.
